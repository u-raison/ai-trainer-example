配置文件写法

settings.json 支持注释。下面两份可以直接复制：一份把补全尽量全部打开，一份用来模拟没有任何提示的考场环境。改完用 Developer: Reload Window 生效。

A. 补全尽量全开

{
    // 语言服务：Default 即有 Pylance 用 Pylance，否则 Jedi
    "python.languageServer": "Default",

    // 自动弹出补全，字符串里也弹出可把 strings 改成 "on"
    "editor.quickSuggestions": { "other": "on", "comments": "off", "strings": "off" },
    "editor.suggestOnTriggerCharacters": true,
    "editor.acceptSuggestionOnEnter": "on",
    "editor.tabCompletion": "on",
    "editor.suggest.selectionMode": "always",
    "editor.snippetSuggestions": "inline",
    "editor.wordBasedSuggestions": "matchingDocuments",   // 旧版本用 true
    "editor.suggest.matchOnWordStartOnly": false,

    // 参数提示、悬停、灯泡
    "editor.parameterHints.enabled": true,
    "editor.hover.enabled": true,
    "editor.lightbulb.enabled": "on",

    // 以下三项只在装了 Pylance 时有效
    "python.analysis.typeCheckingMode": "basic",
    "python.analysis.autoImportCompletions": true,
    "python.analysis.completeFunctionParens": true
}

B. 模拟无补全环境（练习用）

{
    "python.languageServer": "None",
    "editor.quickSuggestions": { "other": "off", "comments": "off", "strings": "off" },
    "editor.suggestOnTriggerCharacters": false,
    "editor.wordBasedSuggestions": "off",   // 旧版本用 false
    "editor.snippetSuggestions": "none",
    "editor.parameterHints.enabled": false,
    "editor.hover.enabled": false,
    "editor.lightbulb.enabled": "off",
    "editor.inlineSuggest.enabled": false
}

只想让提示别自动弹出、需要时手动调用，把 quickSuggestions 三项设为 off 即可，Ctrl+Space 仍能手动弹出。

只对 Python 生效的写法

"[python]": {
    "editor.quickSuggestions": { "other": "on", "comments": "off", "strings": "off" },
    "editor.tabCompletion": "on"
}

Tab 键失效的修复顺序

按列出的顺序逐项排查，每一步先看现象，再给修法。editor.tabCompletion 只管片段前缀展开，在补全列表里按 Tab 接受候选靠的是快捷键绑定，二者要分开看。

  1. 状态栏有没有“Tab 键用于移动焦点”

    现象：按 Tab 光标跳出了编辑器。

    修法：按 Ctrl+M（Mac 为 Ctrl+Shift+M）切换，或点状态栏这一项。

  2. 列表里有没有选中某一项

    现象：列表弹出了，但没有任何一项被高亮，按 Tab 只是缩进。

    修法：先按 ↓ 选一项；或设置 "editor.suggest.selectionMode": "always"，让第一项自动选中。

  3. 输入法是否处在组合状态

    现象：中文输入法下 Tab 被输入法接管。

    修法：切到英文输入再试。

  4. 快捷键设置里 Tab 是否还绑着 acceptSelectedSuggestion

    操作：Cmd/Ctrl+K 再 Cmd/Ctrl+S，搜 acceptSelectedSuggestion。

    修法：绑定不见了或被改了，右键该行选“重置快捷键”。

  5. keybindings.json 里有没有人为删除了它

    操作：Preferences: Open Keyboard Shortcuts (JSON)，搜 tab 和 -acceptSelectedSuggestion。

    修法：删掉带 - 前缀的那行，并确认下面的绑定存在。

  6. 有没有扩展抢走了 Tab

    现象：装了 Copilot、Vim、Tabnine 等，Tab 被它们的行内建议或模式占用。

    修法：逐个禁用后 Developer: Reload Window 对比；Copilot 可设 github.copilot.enable 按语言关闭。

  7. 设置被覆盖或被锁定

    现象：改了又变回去，或设置项带锁形图标、写着由组织管理。

    修法：设置页顶部看“用户”和“工作区”两个标签，工作区优先级更高；策略锁定的项只能在策略来源处改。

快捷键绑定的标准写法（放进 keybindings.json）

{
    "key": "tab",
    "command": "acceptSelectedSuggestion",
    "when": "suggestWidgetHasFocusedSuggestion && suggestWidgetVisible && textInputFocus"
}

查出 Tab 到底触发了什么

  1. 命令面板运行 Developer: Toggle Keyboard Shortcuts Troubleshooting
  2. 在编辑器里弹出补全列表，按一次 Tab
  3. 打开“输出”面板，选对应的通道，看触发的命令名
  4. 看完再运行一次同一命令，关闭记录

Tab 暂时修不好时的替代

  • 确认 "editor.acceptSuggestionOnEnter": "on"，改用 Enter 接受
  • 用 ↑ ↓ 选候选，点击候选也能插入
  • 继续输入前缀过滤，只剩一项时按 Enter

配置文件位置与优先级

设置按层叠加，后面的覆盖前面的：默认值，用户，远程，工作区，工作区文件夹，再到按语言的 [python] 块。

内容WindowsmacOSLinux
用户设置%APPDATA%\Code\User\settings.json~/Library/Application Support/Code/User/settings.json~/.config/Code/User/settings.json
快捷键同目录下的 keybindings.json
代码片段同目录下的 snippets/ 文件夹
工作区设置项目文件夹里的 .vscode/settings.json
远程环境远程机器上的 ~/.vscode-server/data/Machine/settings.json
Pylance 分析配置项目里的 pyrightconfig.json，或 pyproject.toml 中的 [tool.pyright]

快速打开：Cmd/Ctrl+Shift+P，输入 Preferences: Open User Settings (JSON) 或 Open Workspace Settings (JSON)。便携模式下设置在 VS Code 目录旁的 data 文件夹里。设置项被系统策略锁定时，改 settings.json 通常压不过策略。

考场 10 秒自检

看环境有什么

  1. 右下角状态栏有没有 Python 版本，没有说明没选解释器或没装 Python 扩展
  2. 新建 .py，输入 os.，弹出成员列表说明语言服务可用
  3. 扩展面板确认有没有 Pylance、Jupyter、Copilot

没有补全时的兜底

  • dir(对象) 配合关键词筛选，找函数、方法、常量名
  • help(函数) 或 inspect.signature 查参数
  • plt.setp(画图对象) 查 matplotlib 参数和可填的值
  • 故意填错，看 Did you mean 提示
考试机的环境通常由管理员统一配置，是否允许调整设置请先向考务人员确认。自己的电脑上可以放心按本页逐项开关，提前摸清每一项的效果。
