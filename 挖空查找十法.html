十个办法

01

点号补全列表

编辑器内

适用场景

空在点号后面，要填函数名、类名、方法名、常量名。

前提条件

  • 已装 Python 扩展，状态栏显示 Python 版本
  • python.languageServer 不是 None
  • 补全变量（cap.、df.）时，前面要有它的赋值语句

案例

忘了把一帧写成图片的函数叫什么。

cv2.<10>(filename, frame)    # 把一帧写成图片

操作步骤

  1. 删掉 <10>，只留 cv2.，键盘光标放在点号后面。
  2. 一般会自动弹出列表；没弹就按 Control+Space（Windows 为 Ctrl+Space）。
  3. 继续输入记得的字母，如 imw，列表只剩 imwrite。
  4. 按 Tab 或 Enter 确认。

补全看的是键盘光标，不是鼠标指针。想让列表匹配单词中间的字母，在设置里取消 editor.suggest.matchOnWordStartOnly。

02

参数提示

编辑器内

适用场景

函数名已知，忘了参数名、个数、顺序或默认值。

前提条件

  • 语言服务器可用（同 ①）
  • 设置 editor.parameterHints.enabled 为开（默认开）

案例

忘了 makedirs 里“已存在也不报错”的参数叫什么。

os.makedirs(output_dir, <3>=True)

操作步骤

  1. 把空删掉，写成 os.makedirs(output_dir, ，光标停在逗号后面。
  2. 输入 ( 或逗号时自动弹出；没弹就按 ⌘+Shift+Space（Windows 为 Ctrl+Shift+Space）。
  3. 看到签名 makedirs(name, mode=0o777, exist_ok=False)，当前位置的参数加粗。
  4. 填入 exist_ok。

OpenCV 是 C++ 编译库，签名可能显示不全，这时改用 ⑥ help。

03

两个点之间的空

编辑器内

适用场景

形如 模块.<空>.函数，中间是子模块或对象，例如 os.path、np.random。

前提条件

  • 补全可用时用补全
  • 补全不可用时只需能运行 Python

案例

拼接路径的函数 join 前面该填什么。

filename = os.<13>.join(output_dir, "a.jpg")

操作步骤

  1. 只留 os. 触发补全，输入 pa，出现 path。
  2. 补全不可用时，在草稿里运行验证，删掉再交卷：
print([n for n in dir(os) if "path" in n])
print("join" in dir(os.path))      # True 就对了

规律：凡是处理路径字符串的函数，都在 os.path 里。

04

转到定义，进声明文件

编辑器内

适用场景

补全列表太长或不完整（OpenCV 常见），想直接浏览整个库的函数签名。

前提条件

  • 语言服务器可用
  • 该库带 .pyi 声明文件
  • 光标要放在代码里已写好的名字上，不是空本身

案例

想查 cv2 里所有跟 write 有关的函数。

cap = cv2.VideoCapture(video_path)   # 光标放在 VideoCapture 上

操作步骤

  1. 光标放在 VideoCapture 上，按 F12，或按住 ⌘ 点击它（Windows 为 Ctrl+点击）。
  2. 跳进一个 .pyi 文件，里面列着每个函数的完整签名。
  3. 在该文件里 ⌘+F 搜 def imwrite，直接看到参数。
  4. 按 Ctrl+- 回到原位置（部分键盘设置下是 Alt+←）。

跳不过去时，运行 print(cv2.__file__) 找到目录，手动打开同目录的 __init__.pyi。

05

dir 按关键词找名字

不依赖插件

适用场景

补全不可用，或只记得名字里的一部分字母（开头或中间）。

前提条件

  • 只需能运行 Python，不需要任何扩展
  • 括号里不加引号：dir("cap") 查的是字符串，dir(cap) 才是你的变量

案例

忘了 cv2 里写图片的函数，只记得有 write。

import cv2
for n in dir(cv2):
    if "write" in n.lower():
        print(n)            # imwrite、VideoWriter 等

换场景只改两处：括号里的对象，和条件

想找对象条件
DataFrame 里 drop 开头的方法dir(pd.DataFrame)n.startswith("drop")
对象 cap 有什么方法dir(cap)not n.startswith("_")
matplotlib 里含 bar 的函数dir(plt)"bar" in n
cv2 视频属性常量dir(cv2)n.startswith("CAP_PROP")
06

help 查参数

不依赖插件

适用场景

函数名已知，补全又看不到参数，需要参数名和含义。

前提条件

  • 只需能运行 Python
  • 写 help(函数名)，函数名后面不加括号

案例

忘了 to_excel 里指定引擎的参数叫什么。

import pandas as pd
help(pd.DataFrame.to_excel)        # 第一行就是签名，含 engine=None

# 内容太长时，只看开头一小段
print(pd.DataFrame.to_excel.__doc__[:300])

操作步骤

  1. 运行后看输出的第一行，那是完整签名。
  2. 按空格翻页，按 q 退出。
  3. OpenCV 查具体方法，如 help(cv2.imwrite)、help(cv2.VideoCapture.read)，比查整个类短得多。
07

故意填错，看报错提示

不依赖插件

适用场景

名字记个大概，想让 Python 帮你纠正；或不知道函数有哪些必填参数。

前提条件

  • Python 3.10 及以上才有 Did you mean（你的 3.11 满足）
  • 只有 AttributeError、NameError 这类错误才带建议

案例

# A 名字拼错
df.fillnaa(0)
# AttributeError: ... has no attribute 'fillnaa'. Did you mean: 'fillna'?

# B 不知道必填参数
os.makedirs()
# TypeError: makedirs() missing 1 required positional argument: 'name'

# C 参数名猜错
os.makedirs("a", exist=True)
# TypeError: ... got an unexpected keyword argument 'exist'

填错的代码查完要改回来再交卷。C 类错误没有建议，再配合 ② 或 ⑥ 查正确名字。

08

从代码上下文推断

推断与回溯

适用场景

什么工具都不想用，或环境里什么都没有。

前提条件

无。靠变量名、返回值、注释和命名规律。

代码线索答案
ret, frame = cap.<空>()返回两个值，一个布尔一个画面read
fps = cap.get(cv2.<空>)变量叫 fpsCAP_PROP_FPS
if not cap.<空>():判断是否打开，is 开头返回布尔isOpened
df['成绩'].<空>(median_score)用中位数“填充”fillna
df.<空>(subset=['客户'])subset 是 dropna 的参数dropna
cap = cv2.<空>(video_path)首字母大写是类，变量叫 capVideoCapture
(A) <空> df['学院'].isna()满足任一条件就留下|

规律：类名首字母大写；is 开头返回布尔；常量全大写；成对记忆，如 imread/imwrite、get/set、open/release。

09

全项目搜索

推断与回溯

适用场景

考场文件夹或你自己的项目里，别的脚本用过同样的函数。

前提条件

无，VS Code 自带。

案例

想不起 to_csv 的参数怎么写。

  1. 按 ⌘+Shift+F（Windows 为 Ctrl+Shift+F）。
  2. 输入 to_csv，下方列出所有文件里出现的位置。
  3. 点开某一条，直接看当时的完整写法。

⌘+F 只搜当前文件；⌘+Shift+F 搜整个文件夹，找示例代码更有用。

10

时间线与撤销

推断与回溯

适用场景

你自己改过代码，想找回之前的写法，比如挖空前的完整版。

前提条件

  • 时间线只记录按过保存（⌘+S）的版本
  • 撤销只在文件没关闭时有效

操作步骤

  1. 打开资源管理器（⌘+Shift+E），展开最下方的“时间线”。
  2. 点某一条历史记录，与当前版本并排对比，差异行有颜色。
  3. 想恢复，右键该条目选“还原内容”。
  4. 文件没关时，也可以按 ⌘+Z 逐步撤销。

也可以右键一个文件“选择以进行比较”，再右键另一个文件“与已选项目进行比较”，完整版和挖空版的差异一目了然。

考场流程：先看状态栏有没有 Python 版本，在新文件里输入 os. 测试补全。能补全就用 ①②，不能就用 ⑤⑥，最后统一检查变量名、括号、缩进，并删掉草稿里的 print(dir(...))。
